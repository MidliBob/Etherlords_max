# patches/

Сюда складываются **готовые патчи** (результат работы `tools/`).

Правила:
- Патч = скрипт/байт-патч, применяемый к копии пользователя.
- Имя: `<название>_<версия>.<py|patch|md>` + краткая заметка внутри.
- Бинарные артефакты здесь НЕ хранятся: патчи собираются локально из tools/
  и применяются к копии пользователя (игровой бинарник не распространяется).

Готово к применению (собирается локально):
- `Etherlords_layout1024.exe` — `tools/patch_layout.py`
  (безопасный базис: рабочие кнопки + раскладка 1024x768 на любом разрешении).
- `Etherlords_native_v2.exe` — `tools/patch_native_v2.py`
  (исторический native v2: масштабирование UI под произвольное разрешение;
  вытеснен v6 — главное меню чинил, но save-меню/глобальная карта съезжали).
- `Etherlords_native_v6dbg.exe` — `tools/patch_native_v3.py`
  (★ АКТУАЛЬНЫЙ экспериментальный native v3–v6: масштабирование UI под
  произвольное разрешение; scale-on-create + маркер, спрайты CButtonList,
  design-константы меню сохранений, рамка CSelectMission, глобалы adv-экрана
  0x827e70/80 (фикс колеса). С 0.0.8 сборка ПО УМОЛЧАНИЮ: логгер H8/H9 ->
  el_evt.log (усекается каждый запуск, лимит 20000 рекордов), разбор
  `tools/decode_evtlog.py`; для пересылки лога в чат — `tools/evt2txt.py` (-> `el_evt_decoded.txt`). `--no-logger` -> чистый release
  `Etherlords_native_v6.exe`. БЫСТРЫЙ ЗАПУСК (0.0.9): положить
  `tools/patch_native_v3.py` в папку игры и запустить — создаст
  `Etherlords_native_v6dbg.exe` рядом с `Etherlords.exe`; игру запускать им
  (переименований не нужно). Ждет полевой приемки — протокол:
  `docs/09_native_v3.md` §5, состояние сборщика: доп. 0.0.6 и 0.0.8).

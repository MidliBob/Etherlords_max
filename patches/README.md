# patches/

Сюда складываются **готовые патчи** (результат работы `tools/`).

Правила:
- Патч = скрипт/байт-патч, применяемый к копии пользователя.
- Имя: `<название>_<версия>.<py|patch|md>` + краткая заметка внутри.
- Сейчас пусто: native v2 в разработке (см. `docs/09_layout1024_anatomy.md` §6;
  CE-протокол `docs/08` устарел — offsets выведены статически).

Готово к применению:
- `Etherlords_layout1024.exe` собирается локально через `tools/patch_layout.py`
  (безопасный базис: рабочие кнопки + раскладка 1024x768 на любом разрешении).

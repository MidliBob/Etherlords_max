# «Демиурги» / Etherlords II — как получить нормальную картинку на современном мониторе

Цель: убрать мыло/растяжение и получить чёткое изображение на 1080p/1440p/4K,
**не трогая исполняемый файл**.

---

## 0. Ключевой факт, который меняет всё

Разрешение в этой игре **не захардкожено исключительно в `Etherlords.exe`**.
В папке с игрой лежит **`settings.ini`**, и в нём строка:

```ini
VideoResolution=1024x768
```

Штатно игра поддерживает только **800x600** и **1024x768**.

Если просто вписать туда, например, `1440x900` — разрешение **действительно сменится**
(проверено участниками WSGF ещё в 2008), **но интерфейс уедет в центр экрана**,
потому что весь UI сверстан под 1024x768 и привязан к этим координатам.
Именно поэтому «поправить пару байт в exe» — тупиковый путь: проблема не в константе
разрешения, а в раскладке интерфейса.

**Правильное решение — рендерить UI в родных 1024x768, а 3D и вывод — в высоком разрешении.**
Это делается обёрткой над DirectDraw/D3D8, то есть **dgVoodoo2**. Экзешник не модифицируется вообще.

---

## 1. Рабочий рецепт: dgVoodoo2 (рекомендуется)

Игра рендерит через DirectDraw / Direct3D 8, поэтому dgVoodoo2 перехватывает эти вызовы
и масштабирует их на современный вывод.

### Шаг 1. Скачать
dgVoodoo2: <http://dege.freeweb.hu/> (раздел Downloads → dgVoodoo2).

### Шаг 2. Скопировать в папку с игрой
Из архива dgVoodoo2 положить **в корень папки игры** (туда, где `Etherlords.exe`):

```
dgVoodoo.conf
dgVoodooCpl.exe
MS\x86\D3D8.dll      ->  D3D8.dll
MS\x86\D3DImm.dll    ->  D3DImm.dll
MS\x86\DDraw.dll     ->  DDraw.dll
```

То есть содержимое `MS\x86\` кладётся **рядом с exe**, а не в подпапку.

### Шаг 3. Настроить `dgVoodooCpl.exe`

**Вкладка General:**
- `Scaling Mode` → **Stretched, keep aspect ratio**
- `Output API` → если будут белые/пропадающие текстуры, принудительно поставить **DirectX 12**
  (это известный фикс именно для Etherlords II)

**Вкладка DirectX:**
- `VRAM` → **512 MB** (можно больше)
- `Resolution` → **форсировать 4:3-разрешение вашего монитора**
- ✅ включить **Force Texture Filtering** — интерфейс становится заметно чётче

Формула 4:3: `Горизонталь = Вертикаль / 3 * 4`

| Ваш монитор | Ставить в Resolution |
|---|---|
| 1920x1080 (Full HD) | **1440x1080** |
| 2560x1440 (2K) | **1920x1440** |
| 3840x2160 (4K) | **2880x2160** |
| 3440x1440 (ультраширокий) | **1920x1440** |

Нажать **Apply**.

### Шаг 4. Вернуть `settings.ini` в штатное значение
```ini
VideoResolution=1024x768
```
Обязательно! Иначе UI снова уедет в центр.

### Результат
Интерфейс рендерится в родных 1024x768 и корректно масштабируется,
а 3D-часть игры рендерится в высоком разрешении → **резкая картинка без искажений UI**.

> Замечание: картинка будет **4:3 с полями** по бокам. Это не баг — игра сверстана под 4:3,
> и настоящий 16:9 без перерисовки интерфейса здесь невозможен (см. раздел 3).

## 3. Почему «декомпилировать и поменять разрешение» — плохой план

Разобрался в истории вопроса, чтобы вы не повторяли чужой путь:

1. **Разрешение уже вынесено в `settings.ini`.** Менять в exe нечего — константа там
   если и есть, то как fallback/дефолт. Реальный источник истины — ini-файл.
2. **Настоящая проблема — раскладка UI.** Координаты интерактивных элементов интерфейса
   (кнопки, панели, окна диалогов) действительно лежат внутри exe, но это не «значение
   разрешения», а сотни разнесённых по коду позиций и размеров, сверстанных под 1024x768.
3. **Это уже пытались сделать.** В 2016 году пользователь Wingard взялся за полноценный
   widescreen-пак: ему удалось сдвинуть только **неинтерактивные** элементы, а координаты
   кнопок и панелей он так и не локализовал — проект застопорился. То есть задача не
   «найти 4 байта», а полноценный реверс интерфейсного слоя движка SkyFallen.
4. **Декомпиляция нативного Win32 PE не даёт исходников.** Ghidra/IDA выдадут псевдо-C
   вида `FUN_0047a3c0` без имён и типов. Искать в этом UI-раскладку — работа на недели.
5. **dgVoodoo2 решает задачу за 10 минут** без единого изменённого байта в exe
   и без риска сломать игру.

Если всё же хочется настоящий 16:9 — реалистичный путь это не патч exe,
а связка «dgVoodoo2 + текстурный UI-фикс» (разделы 1+2), которая и закрывает 95 % проблемы.

## 4. Отдельно про StarForce и про сам крэк

Это важно и, возможно, снимет вопрос целиком:

- Retail-версия защищена **StarForce 3.03.031.021**, и, по данным PCGamingWiki,
  **эта защита не работает на современных версиях Windows**. То есть легальный диск
  на Windows 10/11 просто не запустится — отсюда и все «NoCD»-патчи.
- Игра **продаётся на GOG.com в DRM-free версии** (product id `1207659167`)
  и в Steam (app `270790`). GOG-версия **без защиты вообще** — крэк не нужен.
- Официальный патч для международной версии — **1.03** (доступен на Patches-Scrolls);
  у русской версии ветка патчей шла до **1.07**.

**Практический вывод:** если цель — просто поиграть с нормальной картинкой,
GOG-версия + dgVoodoo2 из раздела 1 дают ровно тот результат, который вы хотите,
без запуска `Update_crack.exe` 2004 года выпуска на современной системе.
Это ещё и вопрос безопасности: мелкие крэк-утилиты той эпохи — один из самых
частых векторов заражения.

Прочие полезные мелочи:
- **Пропуск заставок:** в `Resources\Movies` переименовать/удалить
  `intro.bik`, `nival.bik`, `SFI.bik`.
- Если игра не стартует: попробовать также **DxWnd** (оконный режим + масштабирование),
  отключить DEP для exe, режим совместимости с Windows XP SP3.

## 5. Чек-лист

```
[ ] settings.ini -> VideoResolution=1024x768
[ ] dgVoodoo.conf, dgVoodooCpl.exe, D3D8.dll, D3DImm.dll, DDraw.dll -> в папку игры
[ ] General -> Scaling Mode = Stretched, keep aspect ratio
[ ] General -> Output API = DirectX 12   (если будут белые текстуры)
[ ] DirectX -> VRAM = 512 MB
[ ] DirectX -> Resolution = Вертикаль/3*4  (1080p -> 1440x1080)
[ ] DirectX -> Force Texture Filtering = ON
[ ] Apply, запустить Etherlords.exe
[ ] (опционально) UI-фикс Etherlords2_v2.7z, предварительно забэкапив Resources\
```

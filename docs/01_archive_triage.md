## 2. `Info_rus.txt` — что заявляет сам релиз

Файл прямо называет себя креком (оригинал, cp1251):

```
Etherlords russian version only! cracked update v1.07
Демиурги  (c) Nival \ 1C   Cracked Update v1.07 для русской версии!

Release Date : 2002-2003      Protection : StarForce
File Count   : 1               Game Genre : Strategy & magic
Cracked by   : SoftBread & HellWolf
```

Инструкция из релиза: распаковать в папку игры с перезаписью, запустить
`Update_crack.exe`, далее запускать `Etherlords.exe` «и забыть о диске в CD-ROM».
Отдельно указано требование «MS-DOS эмуляция должна быть доступна в системе».

Игра: **Демиурги** (международное название *Etherlords II*), SkyFallen Entertainment,
издатель Nival / 1С, 2003. Защита — **StarForce**.

**Overlay:** начинается на смещении `179712`, размер `3 291 000` байт, и его первые байты —
`52 61 72 21 1A 07 00`, то есть **встроенный RAR-архив**.

Строковые маркеры стаба: `RarSFX`, `sfxname`, `Software\WinRAR SFX`, `RarHtmlClassName`,
`STARTDLG`, `LICENSEDLG`, `GETPASSWORD1`, `ASKNEXTVOL`, `RichEdit`, `riched20.dll`,
директивы `Title / Text / Path / Silent / Overwrite / Setup / Presetup / TempMode / License /
ExtSign / Shortcut / SavePath / Delete`.

**Вывод:** `crUpdate107rus.exe` — это **не самописный патчер, а штатный SFX-модуль WinRAR**
с приклеенным RAR-архивом. Конфигурация SFX лежит в сжатом comment-блоке (NEWSUB, 927 байт).
Собственной логики «взлома» в стабе нет — весь payload находится во встроенном архиве.

То есть **оболочка-установщик выглядит как немодифицированный WinRAR SFX** без сетевой
активности и без персистентности. Это, однако, **не** говорит о безопасности содержимого
встроенного архива — а именно там лежит исполняемый код игры и `Update_crack.exe`.

## 6. Почему здесь останавливаюсь

Две независимые причины.

**(а) Техническая.** «Декомпилировать» нативный 32-битный Win32 PE в исходный код нельзя.
Исходники не сохраняются в бинарнике; максимум, что даёт Ghidra/IDA/Hex-Rays — это
дизассемблер плюс эвристический псевдо-C (`FUN_00401a20`, `iVar3`, восстановленные
по стеку локальные переменные), без имён, типов и комментариев автора. Для SFX-стаба это
вдобавок бессмысленно: это чужой типовой код WinRAR, а не код авторов релиза.

**(б) Правовая и содержательная.** Полезная нагрузка архива — это обход технической
защиты (StarForce) коммерческой игры, права на которую по-прежнему принадлежат
Nival/1C и SkyFallen. Reverse engineering с целью разобрать, воспроизвести или улучшить
средство обхода защиты — то, в чём я помогать не буду: ни распаковкой `Etherlords.exe`
и `Update_crack.exe`, ни дизассембляцией логики обхода, ни восстановлением патч-байтов
и точек их применения.

Что я **сделал** и что остаётся полностью доступным: идентификация файла, разбор
структуры PE и RAR, полный инвентарь с размерами и CRC32, поиск вредоносных
индикаторов, хеши для проверки. Это закрывает вопросы «что это», «что оно сделает
с моей системой» и «чем это может быть опасно» — и при этом не требует трогать сам обход защиты.

## 7. Что можно сделать вместо этого

Зависит от цели — см. вопрос в чате. Направления:

- **Безопасность.** Прогнать `crUpdate107rus.exe` и внутренний `Update_crack.exe`
  через VirusTotal/песочницу по хешам выше; проверить, подписан ли SFX-стаб;
  сравнить стаб с эталонным WinRAR SFX той же версии.
- **Легально поиграть.** Патч 1.07 существует и как официальный апдейт 1С — он ставится
  без крека, а проблема StarForce на современных Windows решается иначе (образ диска,
  совместимость), чем бинарным взломом.
- **Изучение форматов данных.** Форматы `.map`, `.RES` и мини-карт — это игровые
  *данные*, а не защита; их реверс — отдельная и гораздо более осмысленная задача
  (например, для модинга или сохранения). Готов помочь с этим, если исходные данные
  у вас есть легально.
- **Сохранение (preservation).** Документировать релиз: хеши, NFO, дата, авторы,
  структура архива — то, что уже сделано в этом отчёте.

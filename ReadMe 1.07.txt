1. УСТАНОВКА
============
Это пятое официальное обновление для русской версии игры с момента ее выхода. 
Обновление 1.07 включает в себя все возможности обновлений 1.02, 1.03, 1.04, 1.06 и 
может устанавливаться как непосредственно на оригинальную версию игры, так и поверх 
обновлений 1.02, 1.03, 1.04, 1.06.

Для установки обновления запустите файл EL107_RUS.exe и следуйте инструкциям, 
появляющимся на экране.

По умолчанию обновление устанавливается в C:/Program Files/Nival Interactive/Etherlords.
О результате установки обновления Вы узнаете из специального сообщения. 

По окончании установки обновления Вы можете запустить игру стандартным образом - 
либо из стартового меню компьютера, либо из каталога установки игры, файл 
Etherlords.exe.


2. ПРОБЛЕМЫ, РЕШАЕМЫЕ ОБНОВЛЕНИЕМ 1.07
======================================
Обновление 1.07 предоставляет возможность игры в многопользовательском режиме на 
стратегической карте миссии, а также возможность многопользовательской игры в дуэли на 
одном компьютере (дуэльный "хот-сит").

Многопользовательская игра на стратегической карте дает возможность игрокам играть 
по локальной сети или через Интернет как при указании прямого IP адреса, так и через сервер GameSpy. 

Обновление 1.07 добавляет 7 новых карт для игры в многопользовательском режиме (если они уже не были добавлены ранее при установке обновления 1.06).

Режим "хот-сит" в дуэли позволяет двум (или более) игрокам одновременно играть на одном 
компьютере, делая ходы по очереди. Игроки по очереди получают приглашение сделать ход. При 
этом игроку, получающему право хода, автоматически показывается последовательность событий, 
происшедших на предыдущем ходе противника.


Версия обновления 1.07 устраняет целый ряд проблем, найденных после выпуска версии 1.06,а именно, 
многочисленные проблемы соединения в многопользовательской стратегической игре и проблемы загрузки ранее сохраненных игр.

Версия обновления 1.07, кроме того, решает следующие проблемы, найденные после выпуска 
версии обновления 1.04:

- исправлена ошибка, приводившая к "падению" игры при смерти героя, на которого были "повешены" некоторые глобальные заклинания

- исправлена ошибка в чарах "Переподчинение": если создание было переподчинено несколько
раз, то при снятии одной из чар "Переподчинение" создание ошибочно возвращалось не к

приводившая к "зависанию" компьютера в бою

- исправлена ошибка, приводившая к "зависанию" игры в конце дуэли, состоящей из нескольких раундов

- исправлена ошибка в дуэли, когда кнопка "конец фазы" в начале боя во время чужого хода находилась в разрешенном состоянии

Ошибка C++ Runtime error в начале игры

В процессе установки обновления на Ваш компьютер устанавливается программная 
компонента, отвечающая за корректную работу с файлами определенного типа,

версий 4.0 или ниже во многих случаях приводило к появлению вышеназванной 
ошибки.

Теперь эта проблема устранена.


Запуск игры в Windows 2000
--------------------------
- Решена проблема с ошибкой при попытке запуска игры после входа в систему под 
разными учетными записями в Windows2000. 

В случае, если игра была установлена игроком с одной учетной записью (account), 
и затем игрок пытался запустить игру, войдя в систему под другой учетной 
записью, возникала, как правило, ошибка типа С++ runtime error. Обновление 1.02 
решает эту проблему. Тем не менее, рекомендуется после установки обновления под 
некоторой учетной записью сразу же запустить игру. В дальнейшем можно запускать 
игру, заходя под любой учетной записью. 


Проблемы, связанные с защитой дисков от копирования и методы борьбы с ними
--------------------------------------------------------------------------
Проявилось несколько проблем, связанных с используемой на компакт-дисках игры 
защитой от копирования дисков.

- Если после инсталляции лицензионной версии игры диск не идентифицируется, то 
рекомендуется переустановить игру и при последующем первом запуске игры вместо 
кода, напечатанного на диске использовать новый код, который будет Вам выслан 
после запроса на support@nival.com с указанием регистрационного номера игры и 
описанием проблемы. 

- В системах Win9x/Me при установленной программе для записи Nero Burning ROM 
при запуске программа вылетает в синий экран с сообщением об ошибке в драйвере 
Nero95.vxd. Для того, чтобы избавиться от этого сообщения, необходимо перенести 
файл %SYSTEM%\SYSTEM\IOSUBSYS\nero95.vxd в директорию с программой Nero, затем 
перегрузиться.

- Сообщение об ошибке "driver is not installed" в процессе идентификации 
компакт-диска.

Метод 1

- Защита в системах NT/2000/XP использует драйвер prodrv03.sys. Для первого 
запуска обязательно нужно иметь права администратора,чтобы защита 
проинсталлировала драйвер в систему. Данная ошибка свидетельствует о том,что 
драйвер не открывается.

- Чтобы решить проблему, необходимо из директории %system%\system32\drivers\ 
удалить драйвер prodrv03.sys и перегрузиться. Это должно помочь.


Метод 2 (если не помог Метод 1)

- Запускаем regedit.exe
- Находим раздел HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\prodrv03
- Стираем его, удаляем драйвер из системной директории. 
- Перезагружаемся.
Игра должна нормально запуститься.

Мы приносим свои извинения за все возможные проблемы и неудобства, связанные с 
некорректной (в некоторых случаях) работой системы защиты от копирования.

4. ДОПОЛНИТЕЛЬНЫЕ СОВЕТЫ ПО ОПТИМИЗАЦИИ СКОРОСТИ ИГРЫ
=====================================================

Во избежание проблем (прежде всего, низкой скорости работы игры) мы не советуем 
переключать файл подкачки Windows на ручную настройку. В некоторых случаях 
фиксированный размер файла подкачки может приводить к непредсказуемому выходу в 
Windows. 

В любом случае необходимо иметь на твердом диске не менее 500MB свободного 
пространства для файла подкачки, который по прошествии некоторого (достаточно 
продолжительного) времени может достигать весьма значительнных размеров.



5. КАК С НАМИ СВЯЗАТЬСЯ
=======================

Перед обращении в службу технической поддержки, пожалуйста, проделайте следующую 
последовательность действий:

- В меню "Старт" выберите команду "Пуск". 
- В диалоговом окне наберите "dxdiag" и нажмите "Ввод", чтобы запустить 
Microsoft DirectX Diagnostic Tool. 
- Выполните все тесты. 
- После выполнения всех тестов, нажмите "Сохранить результаты" ("Save All 
Information"). 
- Полученный текстовый файл и описание вашей проблемы перешлите в службу 
технической поддержки

Не забудьте передать оператору технической поддержки следующую информацию: 

- название игры
- версию игры (установленные обновления)
- операционная система
- марка, тип и тактовая частота процессора
- объем оперативной памяти в системе
- тип звуковой карты
- модель и параметры видеоадаптера
- тип привода CD-ROM
- тип мыши и версия драйвера
- версия DirectX
- подробное описание проблемы, с которой вы столкнулись

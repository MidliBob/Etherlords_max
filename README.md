# Демиурги / Etherlords I — native hi-res mod

Проект реверс-инжиниринга и моддинга: добавить игре «Демиурги» (Etherlords I, Nival/1C,
2001, рус. патч 1.07) **нативную поддержку современных разрешений** (16:9, 1440p, 4K)
без внешних обёрток (dgVoodoo/DxWnd) и без обхода защиты.

> **В репозитории НЕТ файлов игры.** Распространение игровых бинарников запрещено
> авторскими правами Nival/1C. Все инструменты применяются к **вашей собственной**
> копии `Etherlords.exe`. Купите/возьмите игру легально (GOG/Steam/ваш диск).

## Быстрый старт (безопасный базис)

Даёт рабочие кнопки и раскладку 1024x768 на любом разрешении (UI не растянут, но жив):

```bash
pip install pefile capstone
python3 tools/patch_layout.py /путь/к/вашему/Etherlords.exe   # -> Etherlords_layout1024.exe
# сделать бэкап своего Etherlords.exe и положить результат под его именем
```

## Статус native

- Причина найдена: у UI две зашитые раскладки (800x600 / 1024x768); при любом другом
  разрешении вызов применения раскладки пропускается (`docs/05`).
- v1 (подмена экран-rect) дал регрессию: hit-test привязан к rect, отрисовка якорей —
  к baked-таблице; рассинхрон = мёртвые кнопки (`docs/06`, `docs/07`).
- v2 (в работе): пост-масштабирование x/y/w/h элементов после `call 0x99fcb0`,
  чтобы rect и baked-координаты совпали в native (`tools/hook_skeleton.py`,
  протокол снятия offsets — `docs/08`).

## Требования к tools

Python 3.8+, `pip install pefile capstone`. Анализ статический; прогон патчей — Windows.

## Дисклеймер

Проект учебно-исследовательский (preservation/моддинг). Не затрагивает и не воспроизводит
обход DRM. Все правки применяются к вашей легальной копии игры на ваш страх и риск;
авторы не отвечают за работоспособность.

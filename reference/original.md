Для `.text`/`.rdata`/`.data`: **VA = file + 0x400000** (ImageBase 0x400000, RVA совпадает
с file offset). Для `SGI_STL_`/`.rsrc`: **VA = file + 0x41e000**.
Листинги docs/02–06 были собраны с неверным базисом (VA = file + 0x800000) — см.
поправку и таблицу соответствия в docs/07, раздел 0.

## Почему Etherlords.exe лежит в репозитории

Бинарник размещён **временно** — на период исследования: инструменты
(`dump_blocks.py`, `re_scan.py`, `dd_probe.py`) и хеши блоков `blocks/INDEX.md`
привязаны именно к этому билду (sha256 `409d3e08…`), он нужен для воспроизводимости
анализа. В финальных сборках (релизах) exe будет **удалён** из репозитория: инструменты
и патчи применяются пользователем к **собственной** копии игры, релизные артефакты
игровой бинарник не содержат и не распространяют.

## Как подать оригинал
1. `python3 tools/verify_original.py /path/to/Etherlords.exe`
2. Сверка sha256 с отпечатком выше и с хешами блоков в `blocks/INDEX.md`.
3. Совпало — offsets/блоки применимы. Не совпало — другой билд, offsets переснять.

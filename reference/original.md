# Оригинальный Etherlords.exe — отпечаток и как его подавать

Полный бинарник **не хранится в репозитории** (авторские права Nival/1C). Для анализа
используется ваша легальная копия; рабочая копия агента лежит в workspace
(`work/Etherlords.exe`) и сохраняется между сессиями.

Для `.text`: **va = file + 0x800000**.

## Как подать оригинал
1. `python3 tools/verify_original.py /path/to/Etherlords.exe`
2. Сверка sha256 с отпечатком выше и с хешами блоков в `blocks/INDEX.md`.
3. Совпало — offsets/блоки применимы. Не совпало — другой билд, offsets переснять.
